# Dino Dash website

A responsive static landing page and privacy policy for the Dino Dash mobile game.

## Files
- `index.html` — game landing page
- `privacy.html` — privacy policy page
- `assets/` — optimized artwork and screenshots

## Before publishing
1. Replace every instance of `YOUR_SUPPORT_EMAIL@example.com` with an email address you control.
2. Review the privacy policy against the final app code, permissions, and SDKs. Do not publish claims that are not accurate.
3. Add the real Google Play listing URL to the CTA in `index.html` after the app is published. Until then, it says the game is coming soon.
4. Commit all files to a public GitHub repository.
5. In GitHub, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
6. Wait for deployment and test both `index.html` and `privacy.html` in a private browser window.

## Suggested repository
`dino-dash-website`

GitHub Pages URLs will look like:
- `https://YOUR-USERNAME.github.io/dino-dash-website/`
- `https://YOUR-USERNAME.github.io/dino-dash-website/privacy.html`

Replace `YOUR-USERNAME` with your GitHub username.
